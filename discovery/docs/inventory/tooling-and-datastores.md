## Datastore decision summary

One relational database holds everything (ADR 0003): topology (relational, constraints, transactions), job queue (SKIP LOCKED), audit, and time series with 7-day retention. It is **PostgreSQL (default) or Oracle** (`OBS_STORE_DRIVER`, ADR 0011, satisfying PDF decision D2); both implement `store.Backend` and pass the same contract suite. No second datastore is added: Oracle reuses the go-ora driver already in the dependency set. Later option behind an interface: `store.Metrics` → ClickHouse. Operational cost: one database (whichever the customer runs) with backups and monitoring.
